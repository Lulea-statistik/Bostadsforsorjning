# Bostadsförsörjning i Luleå

Första webbprototypen finns i [docs/index.html](docs/index.html) för publicering med GitHub Pages från **main /docs**.

Fyra vyer: **Start**, **Nyckeltal**, **Mål** och **Definitioner**. Uppgifterna i [docs/data/content.json](docs/data/content.json) är ett preliminärt inventerat arbetsunderlag från bostadsförsörjningsprogrammet. Kontrollera ordalydelse, sidreferenser och mål före officiell användning. Ingen serie med utfall är importerad: saknad statistik visas som »Ej inläst«, aldrig som noll.

Källor: [Luleås bostadsförsörjningsprogram](https://www.lulea.se/download/18.2b7bdc7f183d5df682e2e379/1662618513901/Bostadsf%C3%B6rs%C3%B6rjningsprogram.pdf), [Boverkets bostadsbrist](https://www.boverket.se/sv/om-boverket/oppna-data/bedomning-av-bostadsbrist/), [Boverkets bostadsmarknadsenkät](https://www.boverket.se/sv/om-boverket/oppna-data/bostadsmarknadsenkaten/).

Nästa steg: kontroll av rapportvärden mot PDF med sidnummer och därefter import av årsvisa utfall och datatäckning för varje indikator.
